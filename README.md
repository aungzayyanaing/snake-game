# Snake Apple Game (Python)

A classic Snake game built with Python's built-in `tkinter`, so there is
nothing to install.

## Play

```bash
python3 snake.py
```

- **Move:** Arrow keys or WASD
- **Pause:** P
- **Restart after game over:** R

Eat the red apple to grow and score a point. Every apple makes the
snake a little faster. Hitting a wall or your own tail ends the game.
Your best score is saved in `highscore.txt`.

## Files

- `snake.py` — the whole game, one file
- `highscore.txt` — created on your first game over (not committed)
